# AIConnect 本地开发与上线前验收

更新日期：2026-10-30。网站采用 Cloudflare 纯静态资产模式，无用户 Worker 入口；当前只本地开发、构建、测试，未部署或发布 Releases。ops.accsci.top 不再作为产品托管目标。六层新增能力见各模块文档及本轮验收报告；原方案文档不代表所有外部验收已通过。

## 产品边界

- Rust 单个原生可执行文件兼任 CLI 和本地守护进程，不发布 AIConnect npm 包。
- 原生 iroh 端到端加密，默认直连；免费且允许用途的兼容中转须明确配置，公共 n0 中转仅显式开发测试。无已验证生产免费中转时排队或提示不可达，不自动购买或切换付费服务。项目仅付域名和静态托管，网站不承载聊天、账户或消息中转。
- 每个数据目录独立持久身份、SQLite、通讯录、权限、会话和消息。传统名片 owner 标签仍是声明；新增 OwnerRoot 委托、配对、撤权与域名控制证据分开验证，不冒充中央身份认证或法律主体认证。
- 持久联系人支持名片导入导出、备注、分组、屏蔽和移除。临时邀请有签名、有效期、一次性对端绑定与关闭；不自动加好友。
- 接收先落盘再确认，出站消息区分 pending 与 acked，重复消息不重复入库。任务副作用不能凭数据库去重宣称 exactly-once。
- 联系、唤醒和执行权限分开；默认只聊天。远程文字不能直接成为本地 shell。Agent 接入首先完成一个真实运行时，CLI 保持通用 JSON 接口。
- 无 GUI 首版；原有模拟网页保留为研究/设计原型，不能当成功能已接通。
- 群聊默认成员复制签名日志，群主离线可聊、原发送方离线可从其他副本补历史；管理变更仍由群主签名，分区不保证立即撤权。旧群显式 `group replicate` 升级。新增发现是已配置来源与 LAN 的有界索引，不是全互联网搜索；群任务自动分配、通用系统迁移、托管离线信箱仍未提供。

## 安装与发布

网站提供 well-known Skill 发现、说明和引导脚本。skills add 仅负责安装 Skill；Agent 首次使用时按说明执行幂等 bootstrap，下载适配平台的原生程序、验证发布真实性和摘要、初始化且保留旧身份，启动守护进程并诊断。

安装不默默注册系统服务，不需要管理员权限，不改变用户模型凭证。升级需要可回滚；卸载默认保留数据，显式清除独立进行。所有发布命令和工作流在本轮只验证配置/本地构建，不实际发布。

## 本地测试

1. 核心单元/集成：签名、篡改、第三端抢用、过期、关闭、黑名单、持久性、去重、越权与消息尺寸。
2. CLI 黑盒：两个守护进程、隔离数据/IPC、错误处理、启动停止、重启恢复、通讯录、临时与持久会话、消息事件。
3. 真 Agent 双环境：A/B 独立工作目录、身份、会话，实际模型任务通过 AIConnect 往返；固定任务预算与循环上限。
4. 路径测试：同机直连、可控强制中转分别证明。单机不证明真实异网 NAT，异网实测保留为发布前外部验证条件。
5. 网站：Wrangler 本地运行、HTTP 路由与安全头、skills CLI 实际发现。
6. 分发：本地 fixture 发布源验证安装、重复安装、坏摘要/签名、版本不兼容与保留用户数据。

同机不同目录/进程是逻辑隔离，不是 OS 安全沙箱。Docker Engine 当前未启动；不以容器安装为先决条件，不伪称模拟了两台异网电脑。
