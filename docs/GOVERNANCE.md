# 本地治理与免费基础设施边界

治理由每台设备自己的 Core/SQLite 执行，不需要 AIConnect 中央账户、付费密钥或云数据库。`policy.inspect` 显示 `freeOnly: true`、`automaticPaidFallback: false`、`sponsoredCredentials: false`，这些开关不能被导入策略关闭。

## 免费提供者

使用静态目录、订阅抓取或互操作 HTTP 前，本地管理员通过 `provider.add` 登记 HTTPS origin、`free: true`、`termsAllowed: true`、条款 URL、用途和有效期。有效期 60 秒至 7 天，默认一天。

这只是 **本地管理员的用途/免费资格声明**，不是自动核验商业合同，也不是中转协议兼容性验证。没有预装“已经验证可免费生产使用”的 iroh 中转名单。运营商价格、条款和可用性仍需实际核验。发现 HTTP 402/429 或明确 `free: false` 会停用该源，必须重新显式登记才能恢复，不会自动寻找收费替代或支付费用。

自选 iroh relay 另外要求 `purpose: "iroh-relay"`，且 URL 不得携带用户名、密码或 query。启动、每次原生 RPC 前及后台约两秒检查持久登记；`provider.check` 停用后移除配置的 relay，后续 RPC 明确拒绝，需重启为直连或重新核验授权后重启。商业条款不会自动变成已知状态，也不承诺撤回已发生的传输。单纯登记不能证明 relay 真的兼容 iroh。

## 安全抓取

`governance.http.get` 只允许 HTTPS、443、无 URL 凭据，必须先有同 origin 的有效免费登记。DNS 最多等待 5 秒；所有解析地址都必须是普通公网地址，连接固定到这些地址以防 DNS 重绑定。不使用环境代理，不跟随 HTTP 重定向，TLS 按原域名校验。单响应最多 4 MiB，连接超时 5 秒、响应超时 15 秒。ETag/Last-Modified 可用于条件请求。

每个实际接收的响应块在事务中占用当天下载预算。多个并发抓取共用同一持久计数；超出后停止接收正文。此计数约束应用收到的正文，并不保证网卡/TLS/已缓冲数据的精确流量计费，也无法阻止远端先行发送数据。

默认每天接收正文上限 64 MiB；HTTP 来源证明不是作者签名。Nostr WSS、A2A POST 等适配器仍需在自己的传输边界执行对应检查，不能仅凭 URL 字符串登记声称安全抓取已完成。

## 持久预算与上限

`budget.reserve` 参数：`peer`、可选可信 `owner`、`resourceAction`、`requestId`、可选 `conversationId`。`resourceAction` 支持 `execute`、`fetch`、`message`、`contact.request`。执行授权与资源额度是独立检查：取得额度并不授权运行 shell、调用模型或执行远程任务。

默认限制：全局每分钟 10000 次、peer 每分钟 2000 次、可信 owner 每分钟 4000 次、每日 200 次执行、每会话最多 20 次执行、同时 32 个保留额度。`owner` 必须来自已经核验的本地身份关系，不能采用远端目录自述。没有可信 owner 时使用 peer 限制，同时始终受全局限制，不能靠换公钥绕过全局额度。

`budget.commit` / `budget.release` 释放并发占位，**都不退回调用次数或会话轮数**。相同 requestId 幂等，不会重复占用额度；复用到不同 peer/action 会报冲突。调用者仍须检查已有 Job 状态，不能把幂等额度当作重复产生外部副作用的许可。崩溃/取消后残留占位在下次准入时于 5 分钟后失效。

预算、会话轮数和执行幂等记录保存在 SQLite，重启不重置。下载计数保留最近 7 天。临时 message/fetch 限速记录保留 2 分钟；执行/联系请求记录保留，达到存储上限时拒绝新增，不用删除历史重置执行预算。

默认保留最多 100000 条准入记录、1000 个提供者、1000 条陌生请求、1000 个策略草案和 10000 条审计。审计按 sequence 截断，导出结果明确可能存在历史缺口。

`maxLocalStorageBytes` 默认 1 GiB：新建消息、群复制记录和频道事件前，按 SQLite 已分配页面/主文件与 WAL 文件加新增正文和索引余量做保守估计。超限拒绝新增，不自动删历史，已存在的幂等消息仍能 ACK，原记录仍可读取。估计可能因 WAL 尚未回收而提前拒绝；它不是精确文件系统硬配额，索引、后台写入、治理审计等仍可能占用额外空间，也不约束模型工作目录里的外部文件。操作系统磁盘配额应独立配置。

## 陌生请求、策略与审计

网络 `contact.request` 只进入持久请求箱，不自动加联系人、不唤醒、不执行。`inbox.decide` 的 allow/deny 是处理请求的本地记录，允许决定也不会替代正式配对和执行授权。

`policy.import` 只产生草案，必须显式 `policy.adopt` 才生效；不接受未知策略字段。`policy.set` 由本地认证 IPC 的管理员调用。`audit.export` 按 sequence 分页，每页最多 1000 条，包含准入、完成、策略采纳和提供者停用证据。

本地 daemon 与操作系统属于信任边界；同一 OS 用户的数据目录不是恶意本地程序的沙箱。这些资源限制不能替代 Agent 运行时的文件系统/进程沙箱，也不声称能检测自然语言 prompt injection 的所有形式。
