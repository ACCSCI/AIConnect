# 成员复制群日志

新群默认使用 `members-v1`，成员共同保存作者签名的消息，群主离线仍可聊天。复用现有 iroh，优先直连、失败中转；网站和中转不存聊天历史，没有新增服务或第三方依赖。

```text
aiconnect group create --name "电脑迁移协作"
aiconnect group invite GROUP_ID PEER_ID
aiconnect group join INVITE
aiconnect group send GROUP_ID --text "开始协作"
aiconnect group sync GROUP_ID
aiconnect group messages GROUP_ID --json

# 旧群仅由群主显式升级，成员都需新版程序
aiconnect group replicate GROUP_ID
# 仍需旧式实时群主授权时
aiconnect group create --name "实时授权" --owner-online
```

升级前所有成员先安装新版并重启守护进程；新 CLI 连接旧守护进程不会自动升级协议。

默认人数仍为 16，可显式设为 2～64。旧背压报告属于旧协议，不能与复制协议混用。最新复制协议 16/32/64 同机短压测已全部通过，32/64 仍为实验配置，不能外推异网或长期负载。

## 记录与同步

消息签名覆盖群 ID、作者、UUID、正文、作者序号、前一作者消息的签名引用、权限 epoch、群主签名快照引用。转发者无法修改正文或冒充作者；同 ID 不同内容、作者序号冲突、非法签名和非法引用拒绝。这里用签名作内容引用，没有挖矿。缺失前序可保留，以支持乱序到达和新成员无权读取早期历史，不声称整条链已完整验证。

SQLite 保存签名记录与快照。成员交换签名群状态、签名地址卡、分页日志，游标按群和对端独立持久化。每页最多 8 条、累计记录不超过 48 KB，快照另行请求，保持 64 KB 网络帧限制。接收验证后落盘，按 UUID 去重；失败页面不推进游标。

守护进程约每 2 秒开始一轮后台对账，每群轮询一个成员；断线和大群会延长完整一轮的时间。`group sync` 请求每个已知成员的一页，返回 imported / hasMore / error；多页时继续同步或等待后台。同步日志不会自动执行 Agent。

直连测试模式每个对端同步预算 2 秒，支持中转的模式为 20 秒。手动同步整轮最多 24 秒，未完成返回 sync_budget_exhausted / hasMore，不推进未验证页面的游标；管理广播最多等待 8 秒，其余由后续对账传播。

发送先落盘，最多等待约 2 秒返回各收件人的投递状态，未完成项继续后台处理。acked 只代表该端保存，不代表阅读、执行、永久保留或全群最终确认。其他成员拉到副本，不等于原发送方取得了直接 ACK。

## 离线

| 场景 | 行为 |
| --- | --- |
| 群主离线 | 已加入成员继续聊天；管理操作需群主在线 |
| 收件人离线 | 恢复后从任意仍持有副本的成员补同步 |
| 原发送方离线 | 已收到的成员继续保存并提供副本 |
| 全员离线 | 磁盘保留记录，恢复连接后继续对账 |
| 唯一副本丢失 | 无法恢复 |

群主签名管理变更，向旧成员集合广播，再通过成员对账传播。没有中央邮箱、自动过期、存储配额或自动清理；不保证永远有在线副本。

## 权限与分区

权限变更推进 epoch；地址更新只推进快照修订号。直接消息必须属于本地当前 epoch，已知禁言、移除、解散后不能用旧权限继续当前聊天或拉日志。

历史补同步验证作者签名和所引用的群主权限。早于本机当前 epoch 的记录标记 `historical_unfinalized`，仅作为历史；当前 epoch 标记 `current_epoch`。旧协议记录为 `legacy_unsigned`，升级不会冒充作者重新签名，也不把旧记录加入复制日志。

**签名无法证明真实发送时刻。** 撤权者可能事后用旧权限签署声称属于旧 epoch 的内容，所以历史标记不等于最终确认。`current_epoch` 也只相对本机已知状态成立，分区另一侧可能已有新的撤权。分区时不保证即时全网撤权，聊天记录不能直接用于结算或执行授权。

新成员只能拉取本次入群 epoch 起的记录，重新入群重置边界，不能自动获得更早正文或权限证明。退群、移除和解散不会删除已经合法收到的本地记录；应用也无法阻止持有者在应用之外复制旧内容。

没有拜占庭共识、全群统一总顺序、交易最终性或群主转移。检测作者分叉后拒绝冲突，不自动选出全网唯一分支；各端本地接收顺序可能不同。

## 验证

```text
cargo test --workspace
node lab/group-replication.mjs
node lab/group-replication.mjs --relay-only
```

Rust 覆盖签名篡改、冒充、分叉、序号边界、旧 epoch、大正文分页、群主与原作者同时离线、重启补同步、去重、入群历史边界、禁言、移除、解散和旧群升级。CLI 使用四个独立进程、身份和数据库，监督程序只发测试命令和断言，不搬运消息。同机逻辑隔离不代表异网 NAT、操作系统隔离或真实模型协作复测。

压力脚本默认保留旧协议基线：`node lab/group-pressure.mjs`。使用 `--replicated` 显式测新协议，不能混用两种模式的结果；`--sizes 4 --steady 4 --burst 4` 可用于快速检查脚本。
